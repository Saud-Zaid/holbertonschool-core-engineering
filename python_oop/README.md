# Python Object-Oriented Programming (OOP)

This repository section covers object-oriented programming concepts in Python, including classes, objects, attributes, methods, encapsulation, data validation, inheritance, polymorphism, abstract base classes (ABCs), multiple inheritance, mixins, and class extension.

## Subdirectories

- `classes_and_object_model`: Introduction to classes, instance attributes, encapsulation with getters/setters, methods, and representation.
- `inheritance`: Inheritance, base classes, method overriding, and polymorphism.
- `abc`: Abstract Base Classes, duck typing, multiple inheritance, mixins, and extending built-in classes.
