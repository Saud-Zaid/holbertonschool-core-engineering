# Python OOP - Inheritance

This project explores inheritance, method overriding, polymorphism, and shared base classes in Python.

## Files and Tasks

- `base_geometry.py`: Base class `BaseGeometry` with `area()` method and `integer_validator()`.
- `1-rectangle.py`: Class `Rectangle` inheriting from `BaseGeometry` with validated private attributes `width` and `height`.
- `2-rectangle.py`: Extended `Rectangle` class with `area()` method and string representation `__str__()`.
- `1-square.py`: Class `Square` inheriting from `Rectangle` with size validation.
- `2-square.py`: Extended `Square` class with custom string representation `[Square] <width>/<height>`.
