# Python OOP - Classes and Object Model

This project introduces Object-Oriented Programming (OOP) in Python using the `Square` and `Rectangle` classes to understand encapsulation, private attributes, properties (getters and setters), instance methods, and string representation (`__str__`).

## Files and Tasks

- `0-square.py`: Empty class `Square` that defines a square.
- `1-square.py`: Class `Square` with private instance attribute `size`.
- `2-square.py`: Class `Square` with type and value validation for `size`.
- `3-square.py`: Class `Square` with public instance method `area()`.
- `4-square.py`: Class `Square` with getter and setter properties for `size`.
- `5-square.py`: Class `Square` with public instance method `my_print()` printing `#`.
- `6-square.py`: Class `Square` with `position` attribute, `my_print()`, and `__str__()`.
- `1-rectangle.py`: Class `Rectangle` with private attributes `width` and `height` with getters and setters.
- `2-rectangle.py`: Class `Rectangle` with public instance methods `area()` and `perimeter()`.
