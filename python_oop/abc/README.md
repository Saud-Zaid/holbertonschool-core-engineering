# Python OOP - Abstract Base Classes, Multiple Inheritance & Mixins

This project covers Abstract Base Classes (ABCs), duck typing, multiple inheritance and Method Resolution Order (MRO), mixins, and extending built-in Python classes.

## Files and Tasks

- `animals.py`: Abstract class `Animal` with abstract method `sound`, implemented by `Dog` and `Cat`.
- `shapes.py`: Abstract class `Shape` with `area` and `perimeter`, implemented by `Circle` and `Rectangle`, with `shape_info` demonstrating duck typing.
- `flyingfish.py`: Multiple inheritance demonstration with `Fish`, `Bird`, and `FlyingFish`.
- `dragon.py`: Mixins demonstration with `SwimMixin`, `FlyMixin`, and `Dragon`.
- `verboselist.py`: Custom class `VerboseList` extending Python's built-in `list` with notification messages.
