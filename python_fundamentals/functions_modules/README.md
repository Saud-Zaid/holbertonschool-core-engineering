# Python Fundamentals - Functions & Modules

This project covers the fundamentals of defining functions, function return values, arguments, scope, importing modules, and controlling script execution using `if __name__ == "__main__"`.

## Files and Tasks

- `islower.py`: Function that checks if a character is lowercase using ASCII values (`ord()`).
- `uppercase.py`: Function that prints a string in uppercase using ASCII conversion (`ord()` and `chr()`).
- `print_last_digit.py`: Function that prints and returns the last digit of a number.
- `pow.py`: Function that computes `a ^ b` manually using a loop without `**` or external modules.
- `simple_add.py`: Demonstrates defining functions and controlling execution with `if __name__ == "__main__"`.
- `test_import.py`: Demonstrates importing a module without triggering execution guards.
- `add.py`: Imports and uses `add()` from `add_0.py`.
- `calculation.py`: Imports and uses mathematical operations from `calculator_1.py`.
- `variable_load.py`: Imports and prints the variable `a` from `variable_load_5.py`.
