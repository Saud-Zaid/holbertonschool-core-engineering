# Python Fundamentals - Core Data Structures

This project covers core data structures in Python, including lists, tuples, sets, and dictionaries.

## Files and Tasks

- `print_list_integer.py`: Prints all integers of a list, one per line, formatted with `:d`.
- `element_at.py`: Retrieves an element from a list at a specific index safely.
- `replace_in_list.py`: Replaces an element of a list at a specific position.
- `print_matrix_integer.py`: Prints a 2D matrix of integers.
- `add_tuple.py`: Adds two tuples containing up to 2 integers.
- `common_elements.py`: Returns a set of common elements in two sets.
- `update_dictionary.py`: Replaces or adds a key/value pair in a dictionary.
- `best_score.py`: Returns the key with the biggest integer value in a dictionary.
