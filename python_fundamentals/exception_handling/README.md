# Python Fundamentals - Exception Handling

This project covers handling errors and exceptions in Python using `try: / except: / finally:` and raising exceptions.

## Files and Tasks

- `safe_print_list.py`: Prints `x` elements of a list safely without using `len()`.
- `safe_print_integer.py`: Prints an integer with `"{:d}".format()` safely and returns a boolean.
- `safe_print_list_integers.py`: Prints only integer elements from a list up to `x` elements.
- `safe_print_division.py`: Divides two integers safely and uses `finally:` to display the result.
- `raise_exception.py`: Raises a `TypeError`.
- `raise_exception_msg.py`: Raises a `NameError` with a custom message.
